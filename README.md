

# Simple Interest Calculator

## 📌 Description

A Simple Interest Calculator is a basic program that calculates the simple interest and total amount based on the principal amount, rate of interest, and time period.

## 🧮 Formula

**Simple Interest = (P × R × T) / 100**

Where:

* **P** = Principal Amount
* **R** = Rate of Interest
* **T** = Time Period

**Total Amount = Principal + Simple Interest**

## 💻 Example

If:

* Principal = ₹10,000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (10000 × 5 × 2) / 100 = ₹1,000**

**Total Amount = ₹10,000 + ₹1,000 = ₹11,000**
